# Module 03: Data Analysis & Visualization

A beginner/intermediate notebook for practicing Pandas, NumPy, dataset exploration, data cleaning, summary analysis, and Matplotlib charts.

## Open in Google Colab

[Open the notebook in Google Colab](https://colab.research.google.com/github/Omlokare/module-01/blob/main/module-03/data_analysis_visualization.ipynb)

## What the notebook covers

- Create and load a small synthetic CSV dataset
- Inspect rows, columns, data types, summary statistics, and missing values
- Remove a duplicate and fill a missing value
- Add a calculated revenue column
- Group and summarize data using Pandas and NumPy
- Create bar, line, and pie charts with Matplotlib
- Complete a short practice challenge

The notebook is self-contained and uses no external dataset downloads. Run its cells from top to bottom in Google Colab.
