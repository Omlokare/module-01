# Module 04: Machine Learning Fundamentals

A Google Colab-ready introduction to the supervised machine learning workflow using Scikit-learn's Iris dataset.

## Open in Google Colab

[Open the notebook in Google Colab](https://colab.research.google.com/github/Omlokare/module-01/blob/main/module-04/machine_learning_fundamentals.ipynb)

## What you will practice

- Load a beginner-friendly labelled dataset
- Separate features from target labels
- Split data into training and test sets
- Train a Scikit-learn classification pipeline
- Evaluate results with accuracy, precision, recall, F1 score, and a confusion matrix
- Make a prediction for a new example

The notebook uses Scikit-learn's built-in Iris dataset, so it does not need a separate data file. Run each cell from top to bottom in Colab.
