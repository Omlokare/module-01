# Module 02: Python Mini Project

## Expense Tracker

A beginner-friendly command-line project for recording expenses, viewing entries, and calculating a total. It uses Python's standard library only and saves entries in `expenses.csv` in the current working directory.

## Run

```bash
python expense_tracker.py
```

Choose an option from the menu. To record an expense, enter a short description, category, and non-negative amount. The project stores the entries in a CSV file so they remain available after the program closes.

## Concepts practiced

- Variables and user input
- Lists and dictionaries
- Loops and conditionals
- Functions and input validation
- Reading and writing a CSV file
- Calculating a sum
