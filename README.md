# Module 01: Introduction to AI & Python

Beginner learning notes and runnable Python practice for Day 1–Day 4.

## Learning goals

- Explain Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL).
- Recognize common real-world uses of AI.
- Practice Python variables, loops, functions, and lists.
- Write and run small Python programs.

## Requirements

- Python 3.10 or newer
- A terminal or code editor (VS Code is optional)

Check your Python installation:

```bash
python --version
```

On some systems, use `python3 --version`. If Python is missing, install it from [python.org](https://www.python.org/downloads/) and enable the option to add Python to PATH on Windows.

## Run the examples

From the repository folder, run:

```bash
python practice.py
python mini_programs.py
```

Use `python3` instead of `python` if that is the command on your computer. The programs use only Python's standard library.

## Suggested four-day path

1. **Day 1:** Read the AI, ML, and DL overview. Run `practice.py` and change the sample values.
2. **Day 2:** Explore AI applications and discuss where prediction, recognition, or language tools are useful.
3. **Day 3:** Trace the loops, functions, and lists in the practice examples. Try the mini programs.
4. **Day 4:** Build one small program of your own, such as a quiz or a study planner, and explain how it works.

## Deliverables

- `LEARNING_NOTES.md` — concise notes covering the key concepts and Python foundations.
- `practice.py` — guided examples of variables, lists, loops, and functions.
- `mini_programs.py` — a simple quiz and a grade average calculator.

## What to try next

- Add another question to the quiz.
- Let the grade calculator accept more scores.
- Write a function that converts Celsius to Fahrenheit.
- For an AI experiment, write down example inputs and outputs for a rule-based chatbot. This illustrates a basic program, not a trained ML model.
